# Omnix MCP tool catalog

> Generated by `pnpm catalog` from the live tool registry. Do not edit by hand.

Omnix exposes **80 tools** over MCP (Streamable HTTP at `/mcp`, legacy SSE at `/sse`, and stdio via `pnpm mcp:stdio`).
Read tools never change anything. Write tools follow the connection's permission mode: in *edit with approval* they create a proposal the user reviews; in *autonomous* they commit directly inside allowed projects. Every call is logged in the activity feed.

Read-only resources: `omnix://projects`, `omnix://projects/{projectId}`, `.../tree`, `.../layers/{canvasId}`, `.../timeline/{sequenceId}`, `.../code/{workspaceId}`, `.../document/{documentId}`, `.../slides/{deckId}`, `.../selection`, `.../notes`, `omnix://assets`.

### `apply_operations`
